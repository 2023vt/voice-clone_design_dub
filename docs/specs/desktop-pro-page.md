# Desktop Pro checkout release contract

VoiceStudio Free retains unlimited local voice creation, transcription, dubbing, Stories, Audiobooks, batch jobs, and local exports. Desktop Pro adds production recipes, watch folders, persistent batch rules, revision history, client delivery packages, project preflight, remote-device compute, remote workers, encrypted GPU sharing, and production tools for paid client work. Individual pricing is $99 per user yearly or $299 per user lifetime. Yearly renews; lifetime is one payment with no renewal and includes lifetime updates. Enterprise is a contact plan for customised deployment, policy controls, SSO/SAML, fully private operation without logs or telemetry, and dedicated support. Pro does not change GNU AGPL-3.0 software distribution rights; a separate commercial agreement handles closed-source distribution.

The Electron Pro page shows Pro, Lifetime, and Enterprise cards in one row. Pro and Lifetime let buyers select 1–99 users, show the calculated total, and link to `https://voicestudio.sh/pro` with the plan and quantity. Enterprise links to the commercial contact page. The website may show Lemon Squeezy hosted checkout only when all release gates are true and both live offers are verified. Lemon Squeezy handles payment, receipts, and emailing licence keys. The app activates, validates, and deactivates a key through its public License API. It accepts only the configured store, product, and one of the two purchasable plan variant IDs. Main never returns the key to the renderer after submission. The app checks status when the Pro page opens; activation/deactivation are explicit actions. The activation form opens in a modal from the pricing section. Free workflows do not require a network call.

## Release gates

- Implement the ten advertised Pro capabilities and enforce entitlement in Electron main/backend, not only renderer controls. Remote-device compute, remote workers, and GPU sharing must reject unlicensed activation at their Electron main or backend action boundaries, rather than relying on disabled renderer controls. Verify each capability on macOS, Windows, and Linux. Until this is done, `VOICESTUDIO_PRO_FEATURES_RELEASED` stays unset.
- Fulfil purchased user quantity as the licence activation entitlement. Lemon Squeezy checkout quantity changes the charge but does not by itself change a variant's fixed activation limit, so a verified webhook or equivalent fulfilment step must set and audit the purchased activation count before multi-user checkout is enabled.
- Create live yearly and lifetime Lemon Squeezy variants with licence keys enabled. Verify the yearly subscription interval and the lifetime non-expiring key. Record store, product, and both variant IDs. Confirm each displayed price against checkout, tax presentation, activation limit, renewal and cancellation terms, and refund policy in a live checkout. Test variants must never be used for a production build.
- Review and approve desktop Pro purchase terms and privacy wording with qualified counsel. Until approved, `VOICESTUDIO_PRO_TERMS_APPROVED` stays unset.
- Build Electron with `VOICESTUDIO_PRO_STORE_ID`, `VOICESTUDIO_PRO_PRODUCT_ID`, `VOICESTUDIO_PRO_YEARLY_VARIANT_ID`, and `VOICESTUDIO_PRO_LIFETIME_VARIANT_ID`. Each must match the website's live offer. An unconfigured build cannot activate keys.
- Test purchase, email delivery, activation, reopening, invalid/refunded keys, failed network, deactivation, reinstall, and device move. Resolve the offline and key-storage policy before accepting payments. A checkout success redirect must never grant access.

No paid checkout or feature unlock is live until the gates pass. The desktop Pro plans and features are separate from the `vssaas` Cloud commerce roadmap.
